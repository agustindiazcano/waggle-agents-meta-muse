## Ideas and methods

The author has earlier public projects in related areas (a transactional LLM agent with an MCP boundary, and a workflow engine for coding agents). Only general methods carry over as ideas: tool authorization by authenticated identity, idempotent execution, multi-model review, fault-injection testing, and baseline-versus-ablation reporting. Everything here was designed and written again for robot fleets, with different data models, tools, safety logic, simulator and evaluation.
