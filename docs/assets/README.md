# README banner

`waggle-hive-header.html` is the editable source of the rectangular README banner.
Open it locally in a browser; its canvas is 1600 by 500 CSS pixels. It uses system
fonts and local assets, with no scripts or network requests.

`waggle-hive-header.png` is a Chrome headless screenshot at that size and scale 1.
Capture with `--headless --hide-scrollbars --force-device-scale-factor=1
--window-size=1600,500 --screenshot=<absolute-output-path>` and the HTML file URL.

The Waggle Hive hexagon mark and fleet illustration are original SVG geometry
embedded in the HTML. The Meta symbol is preserved in `meta-logo.svg`, credited to
Meta Platforms, from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Meta_Platforms_logo.svg).
See the [Meta brand resource center](https://www.meta.com/brand/resources/meta/company-brand/).
The symbol identifies the hackathon context described in the project README.
