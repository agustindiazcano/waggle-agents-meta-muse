# Waggle Hive: Submission Checklist

Deadline: Wed Nov 4, 2026, 9:00 PM ET (23:00 in Argentina). Confirm the time zone label on the submission page. Late submissions are not considered.

## Eligibility and rules

- [ ] Project fits Push the Frontier.
- [ ] Not one of the sample anti-projects (medical advice, basic RAG app, simple image analyzer, education chatbot, job screener, nutrition coach, personality analyzer, sports coach, political or war content). Predictive maintenance uses a physical model plus RAG for procedure text, not RAG as the application.
- [ ] Uses Meta models through the Meta Model API and/or open weights (Muse Spark, Muse Spark Open 1026, Muse Voice Transcribe). Stage One requires this.
- [ ] Repository is public.
- [ ] Repository history shows work done during the hackathon only. PRIOR_WORK.md present.
- [ ] Demo video shows only what was built during the hackathon.
- [ ] Assets: rights documented in ASSETS.md.
- [ ] Team size within limit (solo).
